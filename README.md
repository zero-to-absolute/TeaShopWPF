# TeaShop Manager

Настольное приложение для сотрудников чайного магазина: каталог, склад, поставки, заказы, продажи и отчёты в одном окне.

## Что умеет

- вход сотрудника; набор доступных разделов зависит от роли (администратор, менеджер, продавец);
- каталог товаров и категорий, поставщики;
- склад: поставки, движение товара, списания, возвраты покупателей;
- заказы и продажи;
- уведомления и управленческие отчёты;
- администрирование пользователей и настройки приложения.

## Тесты

Проект TeaShopManager.Tests на MSTest проверяет:

- хеширование паролей (SHA-256);
- определение прав доступа по роли, в том числе роль с лишними пробелами и в другом регистре;
- чтение и сохранение настроек: отсутствующий файл, повреждённый JSON, значения вне допустимого диапазона.

## Технологии

C#, WPF, .NET 8, MVVM, Microsoft SQL Server (Microsoft.Data.SqlClient), MSTest.

## Запуск

Нужны Visual Studio 2022 и SQL Server с базой TeaManagementDB. Строка подключения DefaultConnection находится в App.config. Тесты запускаются из обозревателя тестов Visual Studio или командой dotnet test.
